# Toast

Confirmation after an apply, with Undo. It stays until dismissed or until the next apply; Undo restores from the backup and reverses creates and deletes.

Zoom feedback uses the same floating surface at the top-right, separate from the bottom-right save confirmation. It shows the actual percentage (for example, "Zoom 110%") after zoom in, zoom out or reset, including at the zoom limits. It disappears two seconds after the latest zoom action without taking keyboard focus or replacing Save/Undo.
