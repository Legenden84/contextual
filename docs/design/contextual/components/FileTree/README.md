# FileTree

Explorer for the open project: a checkbox per file and folder (tri-state for folders), token counts (folders sum their selected files), excluded items and changed-on-disk badges.

Excluded entries are greyed out with an `excluded` tag and the reason on hover (`ignored: node_modules`, `lock file`, `binary`, `.gitignore`). The header has Filter, Select all, Clear and Respect .gitignore; the root row shows the selected total.
